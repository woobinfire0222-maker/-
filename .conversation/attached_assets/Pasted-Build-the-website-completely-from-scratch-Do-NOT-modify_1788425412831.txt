# 8. Group Chat

Create a real-time group chat.

This is extremely important.

Messages must NOT be stored only in browser memory.

Every chat message must be permanently stored in Supabase PostgreSQL.

Use Supabase Realtime so that messages appear immediately for other connected users.

Suggested message fields:

* id
* room_id
* sender_id
* content
* created_at

When a user opens the chat:

1. Load previous messages from Supabase.
2. Display the chat history.
3. Subscribe to Supabase Realtime.
4. Display new messages immediately.
5. Save every new message to Supabase.

Refreshing the page must NOT erase chat history.

A user who joins later should still be able to see previous messages according to the configured access rules.

Do not implement fake client-only chat.
